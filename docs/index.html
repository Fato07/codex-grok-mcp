SECURITY IS PRODUCT BEHAVIOR

Useful access, narrow authority.

Failures stop visibly. External writes stay explicit. Sensitive state stays out of normal prompts.

⌁

Credentials stay put

One-off calls use your signed-in Grok CLI. Paired gateway credentials stay inside the Grok Bot VM.

◇

Encrypted, exact-target access

AES-256-GCM protects paired frames. Exact Bot IDs and roster fingerprints make target changes visible.

↯

No optimistic retries

An uncertain send stays uncertain. The bridge will not silently duplicate an external write.
