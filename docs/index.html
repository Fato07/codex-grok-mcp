THE ROUTE, NOT THE MAGIC

Every boundary stays visible.

The connector keeps the local CLI path separate from the paired persistent-Bot path.

SECURITY IS PRODUCT BEHAVIOR

Useful access, narrow authority.

Failures stop visibly. External writes stay explicit. Sensitive state stays out of normal prompts.

⌁

Local-first authentication

Uses an existing signed-in Grok CLI. The connector checks the auth file but does not read it.

◇

End-to-end relay encryption

AES-256-GCM protects paired application frames. Gateway credentials never leave the VM.

◎

Exact-target sends

Roster fingerprints and exact Bot IDs make recipient changes visible before a send.

↯

No optimistic retries

An uncertain send stays uncertain. The bridge will not silently duplicate an external write.
